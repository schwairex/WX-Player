# WX Player 1.7.0

- GitHub Releases güncelleyicisi, hem genel hem de sürüm numaralı EXE bulunan sürümlerde doğru EXE'yi seçer. Eski sürüme ait EXE'ler seçilmez; SHA-256 doğrulaması korunur.
- Ana pencere, sol gezinme, içerik rafları ve kartları, canlı TV/EPG ve ortak ayar penceresi koyu, sade bir tasarım sistemiyle yenilendi. Kaynaklardan gelen gerçek içerikler kullanılmaya devam eder.
- Sol menü yeni kurulumlarda ikon görünümüyle açılır. Menü genişletildiğinde ana içerik yeniden boyutlandırılmaz; mevcut menü tercihi korunur.
- Oynatma, kaynaklar, EPG, Discord Rich Presence, favoriler ve kullanıcı verisi işlevleri değiştirilmedi. Discord Application ID aynıdır.

## GitHub Release yayımlarken

**1.7.0'a eski uygulamalardan otomatik geçiş için Release'e yalnız bir WXPlayer Windows x64 EXE yükleyin.** Önerilen ad `WXPlayer.exe`'dir; yanında `WXPlayer-win-x64.zip` ve `SHA256SUMS.txt` bulunabilir. Yerel çıktıdaki `WXPlayer-1.7.0.exe`, aynı EXE'nin sürümlü teslim kopyasıdır; bunu `WXPlayer.exe` ile aynı Release'e ayrıca yüklemeyin. Eski sürümlerin güncelleyicisi birden fazla eşleşen EXE'yi reddeder. 1.7.0 ve sonrası, bu durumu kendi tarafında işleyebilir.
