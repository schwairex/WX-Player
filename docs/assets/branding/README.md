# WX Player marka görselleri

- `wx-logo-horizontal-light-text.svg`: sağlanan özgün SVG, değiştirilmeden kopyalandı. Koyu zemin için beyaz yazı.
- `wx-logo-horizontal-dark-text.svg`: GitHub açık teması için aynı şekiller ve lime marka rengi; yalnız beyaz başlık yazısı koyu renge çevrildi. Türetilmiş dosyada özgün imza/metadata taşınmadı.

Kök README, GitHub’ın desteklediği `picture` öğesiyle ziyaretçinin temasına uygun logoyu seçer. Görseller depo içindeki göreli yollardan yüklenir. Uygulamanın PNG/ICO varlıkları `src/WXPlayer.App/Assets` altındadır.
